# 开源与数据归属声明（Open Source & Ownership）

InkSpirit 是开源数字生命框架。本文件说明代码、数据与内容的归属边界——这是生态级协议的一部分。

## 1. 代码许可

- **InkSpirit Core** 使用 **Apache License 2.0**（见根目录 `LICENSE`）
- 允许：商业使用、修改、闭源衍生产品、二次开发、私有部署
- 要求：保留版权与许可证声明（`NOTICE`），修改文件需注明变更
- 目的：InkSpirit 是"数字生命基础设施"，不是封闭应用——我们希望更多人基于它创造数字生命，而不是要求所有衍生作品永远开源

## 2. 用户数据归属

- **用户创建的 Soul 数据（记忆 / 人格 / 关系 / 成长经历 / 灵魂身份）归用户所有**
- 数据存储在用户电脑本地（SQLite + 形象文件），导出即完整灵魂档案（Soul Archive）
- 用户可随时导出、删除、迁移自己的灵魂数据
- **本地优先，隐私优先**：InkSpirit 不会静默上传任何用户数据、日志或统计信息

## 3. 第三方内容版权

- **用户导入的模型（Live2D / VRM / 图片）版权归原作者**——是否可商用由模型作者的许可决定，用户自行负责
- **第三方 Avatar 不代表 InkSpirit 官方**：社区上传的身体/皮肤仅代表作者本人，InkSpirit 项目不对其内容、许可或质量负责
- 未来 Avatar Gallery / 插件生态同样遵循此原则：官方只提供框架与接口（Avatar SDK），内容归属作者

## 4. 品牌与标识

- 「砚灵」「InkSpirit」是项目名称与品牌标识
- 衍生产品应保留出处（Powered by InkSpirit / 版权声明），但不得暗示与 InkSpirit 官方合作，除非获得明确授权

## 5. 生态原则（对开发者）

基于 Apache 2.0 你可以：

- 做商业桌宠 / 企业 AI 伙伴 / 虚拟角色系统 / AI 陪伴产品（闭源亦可）
- 二次开发客户端、接入自己的模型 Provider、构建自己的身体生态

你不能：

- 声称这是你的原创框架（保留版权声明）
- 以 InkSpirit 官方名义发布内容（除非获得授权）

## 6. 一句话总结

**代码归社区，灵魂归用户，模型归作者，平台归生态。**
